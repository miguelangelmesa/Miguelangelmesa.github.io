# Portfolio

Personal portfolio — **https://miguelangelmesa.github.io**

Single static page, no build step and no dependencies to install. Edit `index.html`
and push to `main`; GitHub Pages redeploys on its own within a minute.

The page is one file: styles, markup and the stage navigation all live in
`index.html`. The only external request is to Google Fonts, and every typeface
falls back cleanly if it fails to load.
